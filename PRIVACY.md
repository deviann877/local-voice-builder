# Privacy

The distributed builder does not request accounts, passwords, tokens, device keys, serial numbers, network addresses or device identifiers. It contains no networking code, analytics, diagnostic upload, bundled audio, original package or personal research material.

The user selects local input and output files through the operating system. Those selections are not saved in settings or logs. FFmpeg receives local audio paths as process arguments; local operating-system process inspection can see them. Conversion errors are replaced with generic messages. Output archives preserve the user's stock files and configuration; users must inspect their own output before sharing it. This program does not certify a user's input archive as anonymous.

The release contains no contributor personal paths or owner-specific model/build information. Publishing account details, platform activity and any future commits can independently identify a publisher. Review them separately before publication.

Do not commit personal working folders, generated voice packages, credentials or captures. This repository deliberately excludes device installation and account access.
